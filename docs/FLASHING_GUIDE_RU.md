# Проверка и прошивка — текущие ограничения

## Проверка текущего содержимого

Из PowerShell в каталоге `programmer\host`:

```powershell
py -m pip install pyserial
py .\sda555xfl_firstwrite_v0_5_2a.py verify COM9
```

Если скрипт лежит в другом каталоге, укажи полный путь к нему. `verify` только читает Flash и сверяет идентификатор/CRC/SHA; эта команда не стирает и не записывает целевую микросхему.

## ВАЖНО — не использовать `first-write` для образа v6

Текущий хост-скрипт v0.5.2a разрешает строгий профиль оригинал → VCS v5 (`E0123039`), а также продолжение после полного стирания именно в этот же VCS-профиль. Образы v6 отличаются по CRC и SHA. Прошивка STM32F103 тоже сообщает старый профиль. В результате текущая утилита не является совместимым способом записи v6.

Не редактировать контрольные суммы в скрипте для обхода защиты и не стирать Flash до того, как программатор будет целиком адаптирован для нового ожидаемого образа. Для любой будущей операции должны быть заранее проверены:

- размер файла `131072` байта;
- целевой CRC32 и SHA-256, сверенные с манифестом;
- наличие отдельной проверенной резервной копии заводского дампа;
- совместимость и host-скрипта, и STM32 firmware с точно этим образом;
- полное read-back сравнение после записи.

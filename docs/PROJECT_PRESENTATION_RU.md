# SDA555XFL OSD Lab — презентация проекта

**Формат:** 12 слайдов, 16:9.\
**Источники:** семь оригинальных пользовательских фотографий в `assets/publication/`.\
**Правило:** векторные схемы допустимы; изображения платы, программатора и экранов не генерируются.

1. От телевизионного OSD к автономной платформе — настоящий CRT с Tetris.
2. Аппаратная основа Sokol A-2010 — обе стороны платы, каждое фото отдельно.
3. Reverse engineering OSD — 40 × 25, 1000 ячеек, 3 байта/ячейку, 3000 байт Character Display RAM, Pointer Arrays, GDW, CLUT, DRCS.
4. Автономный видеовывод — видимое OSD на CRT; наблюдение не заменяет осциллограмму.
5. Архитектура FPI — PC host → USB-UART → STM32F103 → штатные точки платы → SDA555XFL.
6. FPI, верхняя сторона — исходная annotated photo, сигналы D0…D5, FPI ENTER и RESET#.
7. FPI, обратная сторона — исходное фото с сохранённой подписью Nano; актуальный mapping отдельно.
8. Universal FPI Flasher 0.1 — исходный скриншот; RUN OK не трактовать как read-back.
9. Интерактивное OSD: меню и Pong — только текст/векторная подача, без выдуманного скриншота.
10. Tetris / Arcade — реальная фотография CRT; аппаратные нюансы управления требуют проверки.
11. Механическое исследование — оригинальная фотография с предварительной разметкой, не производственный чертёж.
12. Результаты, ограничения и следующий этап — Measured / Observed / Simulated / Pending.

Все изображения встраиваются из исходных файлов. Контактные листы, низкокачественные фотоматрицы и AI-generated фотографии аппаратуры не используются.

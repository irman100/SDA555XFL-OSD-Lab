# FPI — актуальная схема подключения STM32F103

**Текущая архитектура проекта — STM32F103. Старый вариант Arduino Nano не является инструкцией для подключения.**

## Исходные фотографии

- Верхняя сторона: `STM32_FPI_front_points.png`.
- Обратная сторона: `STM32_FPI_back_points (1).png`.

Оба исходника — реальные фотографии платы с пользовательскими аннотациями. Они найдены в библиотеке/текущем обсуждении. Бинарные копии ещё не добавлены в GitHub `assets/publication/`; до их публикации README не должен ссылаться на фиктивные image paths.

**Примечание к обратному фото:** в верхней полосе сохранились исторические подписи Nano D10/D11/D12/A1. Они не являются текущей распиновкой. Использовать STM32F103 mapping из таблицы ниже; для презентации верхнюю полосу фото нужно кадрировать и отдельно показать корректную таблицу STM32.

## 1. Верхняя сторона — существующая резисторная обвязка

P0.0…P0.5 подключаются не к ножкам D103, а к сигнальным площадкам штатных подтяжек R115/R116/R114/R113/R112/R111. Сигнальная площадка — вывод резистора, ближайший к D103.

| STM32F103 | FPI / SDA555XFL | Точка на плате |
|---|---|---|
| PA5 | D5 / P0.5 | R111 |
| PA4 | D4 / P0.4 | R112 |
| PA3 | D3 / P0.3 | R113 |
| PA2 | D2 / P0.2 | R114 |
| PA1 | D1 / P0.1 | R116 |
| PA0 | D0 / P0.0 | R115 |
| PB15 | FPI ENTER / P3.6 | Левый вывод R129 = SDA_3.3 |
| PA8 | RESET# | Верхний вывод R135, узел RESET, +3.3 V |

### Не трогать
- R117 и R118 — по аннотации они идут только на разъём.
- Не путать сигнальную площадку резистора с его другим выводом.
- Не подключаться к ножкам D103 вместо отмеченных площадок штатной обвязки.

## 2. Нижняя сторона — управляющие линии и D6/D7

| STM32F103 | Сигнал | Вывод SDA555XFL |
|---|---|---:|
| PB0 | WR# | 45 |
| PB1 | RD# | 46 |
| PB10 | DDIR | 47 |
| PB11 | ASEL1 | 48 |
| PB12 | ASELO | 49 |
| PB13 | ASEN# | 50 |
| — | NC — не трогать | 51 |
| PB14 | FMOD | 52 |
| PA7 | D7 / P0.7 | 8 |
| PA6 | D6 / P0.6 | 7 |

На штатной обвязке D6/D7 и P1.0…P1.7 почти отсутствуют; их расположение и контекст отмечены на нижнем фото. J29/J30/J31 и J21/J22/J23 не назначать как FPI: по аннотации это другие цепи.

## 3. Архитектура соединения

PC host / Universal FPI Flasher → USB-UART → STM32F103 FPI Engine → отмеченные точки штатной обвязки → SDA555XFL FPI / Flash.

Arduino Nano не является текущим контроллером этого интерфейса. Старые Nano-подписи на обратном фото — историческая разметка, не используйте их как pin mapping.

## 4. Перед любыми операциями

1. Проверить, что аппаратный вариант и целевая микросхема совпадают с профилем.
2. Сохранить полный заводской дамп и проверить его контрольные суммы.
3. Выполнить неразрушающий ID/read этап.
4. Проверить образ, размер 128 КиБ и CRC/SHA до передачи.
5. Не выполнять erase/program при compile-lock; destructive режим требует отдельной ревизии и явного разрешения.
6. После отдельно разрешённой записи прочитать всю Flash обратно и сравнить весь массив байт с исходным BIN.

**Ограничения:** таблица транскрибирована с авторских аннотированных фотографий. Перед пайкой перепроверьте конкретные площадки визуально на физической плате. Цветные линии на фото — рабочая разметка, а не электрическая схема производителя.

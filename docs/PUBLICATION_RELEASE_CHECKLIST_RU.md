## Ограничения точности
- CRT-фото подтверждает визуальный вывод OSD, но не измеряет sync/RGB waveform.
- Flasher screenshot с RUN OK не подтверждает полный физический erase/program/read-back.
- Cutout-фото — предварительная аннотация, не размерный чертёж.
- Старые Nano подписи на обратном FPI фото не являются актуальным pin mapping.
- Заводской ROM и recovery-копии не включать в публикационный ZIP.

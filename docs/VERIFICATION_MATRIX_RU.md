# Матрица проверки SDA555XFL OSD Lab

Статусы разделены на: **подтверждено документом/кодом**, **есть визуальное свидетельство**, **программная модель**, **требуется аппаратная проверка**.

| Область | Что подтверждено | Что не следует утверждать |
|---|---|---|
| Целевая микросхема | SDA555XFL A14, PSDIP-52; плата Sokol A-2010 | Не переносить выводы на другой корпус/вариант без сверки |
| OSD memory map | 40×25, 1000 ячеек, 3 байта/ячейка, Display RAM F448..FFFF; восстановлены pointer arrays/GDW/DRCS | Не считать каждый неописанный XRAM-диапазон полностью известным |
| DRCS | Восстановлена структура 12×10 glyph и тестовый символ | Не путать растровый тестовый символ с полным шрифтом |
| H/V sync | В standalone bench измерены примерно 15,625 кГц и 50 Гц | Фото экрана не подтверждает точность таймингов и аналоговые запасы |

| OSD на CRT | Фото 01.11.2026 показывает Tetris OSD на экране | Не делать из одной фотографии вывод о длительной стабильности/всех режимах |
| FPI ID | Рабочий процесс показывает ID BF D5; создан неразрушающий ID workflow | Не считать только software ID окончательным доказательством всех команд Flash |
| STM32F103 Engine v0.5 | Исходник, safety audit и compile-lock; default ALLOW_DESTRUCTIVE_FPI=0 | Не утверждать, что v0.5 в этой конфигурации выполняет erase/program |

## Правило публикации результатов

Любой результат должен иметь один из четырёх ярлыков:
- **Measured** — физически измерен прибором.
- **Observed** — виден на фото/видео или в логе.
- **Simulated** — прошёл программную модель.
- **Pending** — требует проверки на реальном устройстве.

Не повышать статус simulated/observed до measured без нового аппаратного свидетельства.

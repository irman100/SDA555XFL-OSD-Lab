# SDA555XFL Arcade v0.20 — Native Key Repeat / Auto Gravity / Gray Tiles / Dotted Pong Net (P3.3)

## Исправления
- Основной дефект v0.18/v0.19: автоповтор был подключён к адресу `0x0969` — ветке Pong — вместо цикла Tetris по адресу `0x096F`. В v0.20 на `0x096F` стоит `LCALL tetris_frame_tick`, который обслуживает гравитацию и повтор удерживаемой клавиши. Pong loop не менялся.
- Tetris key-dispatch по адресу `0x0C3D` теперь различает нажатие и отпускание. Нажатие ←/→ сразу двигает фигуру на одну клетку; повтор после 10 игровых тактов, далее через 3. Повторные события той же клавиши не сбрасывают задержку. Отпускание снимает состояние, так что ту же стрелку снова можно нажать сразу.
- ↓ сразу опускает на одну строку, при удержании повторяется каждые 2 такта; hard drop отключён.
- Автопадение: первый шаг на уровне 1 после 18 тактов; на уровне 18 — каждый такт.
- В Pong центральный символ `:` изменён на `.` по адресу `0x14E3`, чтобы убрать вид сплошной палочки; физика Pong не менялась.
- Плитки заменены на светло-серые (face index 1, highlight 3, shade 10). CLUT не менялась, фигуры сохраняют собственные цвета. RGB/яркость/насыщенность — максимум, RGB DAC — 1,2 Vpp.

## Ключевые адреса
- `0x096F -> 0x9260`: Tetris frame tick (gravity + hold-repeat).
- `0x0C3D -> 0x927C`: Tetris key dispatcher (keydown/release).
- `0x1528 -> 0x9272`: сброс repeat-state при запуске.
- RAM `0x39`: удерживаемая клавиша; RAM `0x3A`: интервал повтора. Адрес клавиатурного сканера `0x49` не используется.
- Сканер `0x1B70..0x1C17`, нативные движения/поворот `0x16CE/0x16F1/0x170F` сохранены, кроме отдельного патча левой границы на `0x16D0`.

## Проверки
- ROM размер: 131072 байта; CRC32 `CB2AB894`; SHA-256 `b1e0fed4315c6a829731ce3e80786797470267c3aca1bb8f6b2d784f1ce5943e`.
- Bounded instruction-level 8051 test проходит: непосредственный шаг, задержка, автоповтор, release/re-arm той же клавиши, soft-drop, автоматическая гравитация; 28 ориентаций фигур и байты вне разрешённых диапазонов проверены.
- Ограничение: это не полный эмулятор CPU. Нативные функции движения и шаг/фиксация `0x1739` в контроллерном тесте заглушены, клавиатурный/IR-сканер на железе не эмулируется. Нет проверки на телевизоре. Flash не записывалась.

Бинарные ZIP, исходник сборщика, helper-test и превью собраны локально; сами binary assets пока не загружены в GitHub, потому что предыдущая загрузка не прошла проверку контрольной суммы.

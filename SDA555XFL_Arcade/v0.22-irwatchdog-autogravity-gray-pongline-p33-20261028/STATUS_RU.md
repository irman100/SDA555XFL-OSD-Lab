# SDA555XFL Arcade v0.22 — статус

Ветка: `release/arcade-v0.22-irwatchdog-autogravity-gray-pongline-p33-20261028`

## Причина и исправление
- В v0.18/v0.19 вызов helper был установлен в Pong branch по адресу `0x0969`, поэтому в Tetris не работали таймеры. В v0.20+ корректная точка Tetris — `0x096F`.
- Нельзя трактовать бит `0x40` команды ИК-декодера как физическое отпускание: он может быть частью расширенного кода команды.
- v0.22 использует inactivity watchdog `RAM[0x3B]`: соответствующие повторные ИК-кадры обновляют его до 8 игровых тиков, но не сбрасывают DAS counter. Если кадры после отпускания прекращаются, watchdog очищает held-key latch `RAM[0x39]`, repeat timer `RAM[0x3A]` и свой счётчик.
- NEXT painter сохраняет watchdog RAM на стеке, чтобы не повредить состояние удержания.

## Проверки локальных артефактов
- BIN 131072 байта; CRC32 `8AB10F0B`; SHA-256 `5d5c127dedc82796cb930943b10adb4c89128b8bcc29b107e7e98d8eeae476ad`.
- ZIP integrity PASS, firmware bytes внутри всех ZIP совпадают с BIN.
- Bounded helper emulation PASS: гравитация 18→1 такт по уровням, ←/→ initial delay 10/repeat 3, ↓ repeat 2, watchdog timeout 8, прекращение движения при тишине, геометрия 28 вариантов.
- Скрипты компилируются; разрешённые ROM-патчи проверены; неразрешённых изменённых байтов нет.
- Ограничения: нет полной эмуляции 8051/ИК-приёмника; процедуры движения/фиксации в тесте частично заглушены; на реальном телевизоре не проверено. Flash не записывалась.

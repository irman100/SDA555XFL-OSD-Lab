# SDA555XFL Arcade v0.18 — Auto Gravity / Soft Drop / Controlled Repeat / Blue Tiles / P3.3

## Изменения

- Tetris loop теперь вызывает штатную задержку, обработчик таймеров клавиш и legacy gravity timer. Исправлен пропущенный вызов, из-за которого фигуры зависали.
- Автопадение: 18 тактов на уровне 01, по одному меньше на каждый новый уровень, до 1 такта на уровне 18. Начальный счётчик выровнен с фактической логикой countdown.
- ←/→: один шаг сразу, затем пауза 10 игровых тактов и повторы через 3 такта. При нормальном режиме CPU 33,33 МГц это расчётно около 0,44 с до повтора и около 0,13 с между повторениями.
- ↓: мягкое падение на одну строку; при удержании повтор каждые 2 игровых такта (расчётно около 0,09 с). Мгновенный hard drop отключён.
- Фоновая плитка стала светло-синей, с подсветкой сверху/слева и глубокими синими фасками. Глобальная CLUT не изменялась.
- RGB / яркость / насыщенность — максимум; DAC RGB — 1,2 Вpp. NEXT остаётся привязанным к очереди фигур. Pong, меню и ИК-обработка сохранены.

## Проверка

- Python builder: py_compile PASS; build result PASS.
- BIN: 131072 байт, CRC32 `B0D1942B`, SHA-256 `30e08a3427c3332fab071eec10539da16a69efae9d857c81e253a129aed380fa`.
- Проверены 28 ориентаций фигур, модель repeat cadence, формула gravity timer, размеры ROM и неизменность байтов вне явно разрешённых участков.
- ZIP integrity PASS; прошивка внутри full ZIP совпадает с standalone BIN.
- Расчёты миллисекунд основаны на штатном цикле задержки `0x1A18` и нормальном режиме CPU 33,33 МГц. Фактический телевизионный прогон не выполнялся.
- Физическая Flash не записывалась. Перед прошивкой сохранить полный дамп текущей Flash.

# SDA555XFL Arcade v0.19 — Keyscan-safe repeat + auto gravity / soft drop (P3.3)

## Исправления после обратной связи по v0.18

- Убран конфликт с системной RAM: игровой счётчик автоповтора больше не использует адрес `0x49`, занятый штатным сканером/антидребезгом клавиатуры. Для игрового удержания отведены `0x39` и `0x3A`. Код штатного сканирования клавиатуры `0x1B70–0x1C0F` сохранён без изменений.
- ←/→: одно перемещение сразу; после 10 игровых тактов запускается автоповтор, далее — каждые 3 такта. После отпускания та же стрелка немедленно снова разрешена.
- ↓: soft drop на одну строку; удержание повторяет шаг через 2 игровых такта. Мгновенный hard drop не используется.
- Автогравитация вызывает штатный однострочный шаг вниз и сохраняет штатную обработку блокировки, очистки линий и появления следующей фигуры. Начальный и post-spawn таймеры выровнены на значение 17, соответствующее первому движению на 18-м такте.
- Сохранены светло-синие фасеточные плитки, динамический NEXT, геометрия поля 10×20, максимальные значения RGB/яркости/насыщенности и уровень RGB DAC 1,2 Вpp. Pong, меню и ИК-обработка сохранены.
